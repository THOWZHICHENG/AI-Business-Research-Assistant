# Contributing

This is a personal learning and portfolio prototype. Focus contributions on making the documented CLI clearer, more reliable, or easier to evaluate.

1. Follow [the setup guide](docs/SETUP.md) and work on a descriptive branch.
2. Reproduce the issue. Include the question and expected result without credentials or private documents.
3. Keep changes focused and update documentation when commands, configuration, or behavior change.
4. Check Python syntax and run the affected script. For retrieval changes, use [the evaluation guide](docs/DEMO_AND_EVALUATION.md).
5. In a pull request, explain the problem, changed behavior, validation, and remaining limitations. Label illustrative output and checks you could not run.

There is no automated test suite yet. Do not claim tests or hosted calls passed unless you ran them. Never include `.env`, local environments, downloaded models, or private data.

For a suspected exposed credential, follow [SECURITY.md](SECURITY.md) rather than posting it publicly.
